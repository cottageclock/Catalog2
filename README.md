Contents

	catalog.pdf = listing of items of interest; for each item, info provided is:

		- thumbnail, description, title w/link to subfolder with photos
                  
	Photos = folder containing subfolders of photos
  
		- each subfolder is associated with one item of interest
                  
	index.html = displays catalog.pdf, brings up photo viewer when a link is clicked

Notes:

	catalog.pdf was exported from Mac Keynote app
  
	every catalog.pdf link is hard-coded to the github url of the corresponding subfolder
